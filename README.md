# Vaibhav Chopra | Developer Portfolio

A responsive personal portfolio for Vaibhav Chopra, an aspiring full stack developer focused on Python, web technologies, API integrations, and AI.

## Features

- Responsive layout for desktop, tablet, and mobile screens
- Interactive hero model with scroll-driven 3D spinning
- Dark and light theme toggle
- Mobile navigation sidebar with overlay and keyboard support
- Certificate image buttons with preview modal
- Featured projects with GitHub links
- About, skills, projects, certificates, and contact sections
- Three.js animated background

## Project Structure

```text
THE_PORTFOLIO-main/
|- index.html          Main portfolio page
|- style.css           Core visual styles and theme variables
|- responsive.css      Responsive layout rules
|- interaction.css     Hero model interaction styles
|- script.js            Theme, navigation, modal, and animation logic
|- assets/             Images, certificates, and resume file
```

## Run Locally

This is a static website and does not require a build step or package installation.

1. Clone or download the repository.
2. Open `index.html` in a browser.

For the best development experience, serve the folder with any local static server, then open the provided local URL.

## Customization

- Update portfolio content in `index.html`.
- Adjust colors, spacing, and desktop styles in `style.css`.
- Adjust mobile breakpoints and sidebar styling in `responsive.css`.
- Update scroll interaction and UI behavior in `script.js`.
- Replace images and documents inside `assets/`.

## Technologies

- HTML5
